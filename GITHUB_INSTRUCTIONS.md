# 🐙 Push to GitHub

I have already initialized the Git repository and committed all your files locally.
Now, you just need to send it to GitHub!

### Step 1: Create a Repository on GitHub
1.  Log in to your [GitHub Account](https://github.com).
2.  Click the **+** icon in the top right and select **New repository**.
3.  Name it `portfolio-website` (or anything you like).
4.  **Do NOT** check "Add a README", "Add .gitignore", or "Choose a license" (we already have these).
5.  Click **Create repository**.

### Step 2: Connect and Push
Copy the commands GitHub gives you under **"…or push an existing repository from the command line"** and paste them into your terminal here.

They will look exactly like this (replace `YOUR-USERNAME` with your actual username):

```bash
git remote add origin https://github.com/YOUR-USERNAME/portfolio-website.git
git branch -M main
git push -u origin main
```

### Step 3: Success!
Once you see the upload progress finish, your code is safe on GitHub.
Then we can proceed to the **Mobile View**!
